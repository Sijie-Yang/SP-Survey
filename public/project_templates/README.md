# Frozen backup of the template library

The template library lives online (Supabase `templates`, media on R2). Templates are added and changed there, by admins with the MCP tool `template_publish` or in 平台管理 → 模板管理.

These files are a frozen snapshot from before that move. The site reads them only as a fallback when a template's online row cannot be loaded, plus a few images some templates still link to (`2026-lopes-street-gsv/examples/`, `2026-photo-map/riverfront.svg`, `cover_images/`). Do not edit them to change a template, and do not add new templates here.
